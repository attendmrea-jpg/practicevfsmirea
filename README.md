# Эмулятор командной оболочки (вариант №19)

Практическая работа №1 по дисциплине «Конфигурационное управление».

## Общее описание

Консольный (CLI) эмулятор языка оболочки UNIX-подобной ОС. Работает в
режиме REPL: читает строку, разбирает её на команду и аргументы,
выполняет команду и печатает результат. Реализован на Python 3 без
внешних зависимостей.

Текущий этап: **Этап 2. Конфигурация** — эмулятор настраивается
параметрами командной строки и умеет выполнять стартовый скрипт.
Команды `ls` и `cd` по-прежнему заглушки.

Структура репозитория:

```
src/            исходный код
tests/          модульные тесты
tests/scripts/  скрипты ОС (*.sh) и стартовые скрипты эмулятора (*.vsh)
run.sh          скрипт запуска
```

## Описание функций и настроек

### Приглашение к вводу

Приглашение содержит имя пользователя, имя хоста и имя VFS:
`username@hostname:vfs$`. Имя VFS берётся из имени файла, заданного
параметром `--vfs` (без расширения); без параметра — `vfs`.

### Парсер

Строка делится на команду и аргументы по пробелам. В аргументах
раскрываются переменные окружения реальной ОС, например `$HOME`.
Неизвестная переменная раскрывается в пустую строку, одиночный `$`
остаётся без изменений.

### Параметры командной строки

| Параметр | Описание |
| --- | --- |
| `--vfs ПУТЬ` | путь к физическому расположению VFS |
| `--script ПУТЬ` | путь к стартовому скрипту |

При запуске печатается отладочный вывод всех заданных параметров:

```
[debug] vfs    = tests/data/demo.zip
[debug] script = tests/scripts/stage2_basic.vsh
```

### Стартовый скрипт

Файл `*.vsh` с командами эмулятора, по одной в строке; пустые строки
пропускаются. На экран выводится и ввод (с приглашением), и вывод,
имитируя диалог с пользователем. Выполнение **останавливается при
первой ошибке**: эмулятор сообщает о строке и завершается с кодом 1.

### Команды

| Команда | Описание |
| --- | --- |
| `ls [аргументы]` | заглушка: печатает имя команды и аргументы |
| `cd [путь]` | заглушка: печатает имя команды и аргументы |
| `exit [код]` | завершение работы эмулятора |

### Обработка ошибок

Ошибки не прерывают работу и выводятся строкой `ошибка: <описание>`:

* `<имя>: команда не найдена` — неизвестная команда;
* `cd: слишком много аргументов` — неверные аргументы `cd`;
* `exit: слишком много аргументов`, `exit: требуется числовой
  аргумент` — неверные аргументы `exit`;
* `не удалось прочитать скрипт: ...` — стартовый скрипт не найден;
* `<путь>: строка N: выполнение остановлено` — ошибка в скрипте.

## Сборка и запуск

Сборка не требуется, нужен только Python 3.

```bash
./run.sh
```

Запуск тестов:

```bash
python3 -m unittest discover -s tests
```

Запуск с параметрами:

```bash
./run.sh --vfs tests/data/demo.zip --script tests/scripts/stage2_basic.vsh
```

Демонстрация всех возможностей прототипа, включая ошибки:

```bash
sh tests/scripts/stage1_demo.sh
```

Скрипты ОС: все сочетания параметров командной строки и ошибки
стартового скрипта:

```bash
sh tests/scripts/stage2_params.sh
sh tests/scripts/stage2_errors.sh
```

## Примеры использования

```
user@host:vfs$ ls -l /etc
ls -l /etc
user@host:vfs$ ls $HOME
ls /home/user
user@host:vfs$ nosuchcommand arg
ошибка: nosuchcommand: команда не найдена
user@host:vfs$ cd a b
ошибка: cd: слишком много аргументов
user@host:vfs$ exit now
ошибка: exit: требуется числовой аргумент
user@host:vfs$ exit
```

### Выполнение стартового скрипта

```
$ ./run.sh --script tests/scripts/stage2_error.vsh
[debug] vfs    = <не задан>
[debug] script = tests/scripts/stage2_error.vsh
user@host:vfs$ ls ok
ls ok
user@host:vfs$ nosuchcommand arg
ошибка: nosuchcommand: команда не найдена
ошибка: tests/scripts/stage2_error.vsh: строка 2: выполнение остановлено
```
