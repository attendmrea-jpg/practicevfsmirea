# Визуализатор графа зависимостей Cargo (вариант №19)

Практическая работа №2 по дисциплине «Конфигурационное управление».

## Общее описание

Инструмент командной строки, который строит граф зависимостей пакета
менеджера пакетов Rust (Cargo) и готовит его визуализацию. Готовые
средства для получения зависимостей (сам `cargo`, сторонние библиотеки)
не используются: данные читаются напрямую из индекса репозитория, разбор
версий и построение графа реализованы в проекте. Реализация на Python 3
без внешних зависимостей.

Текущий этап: **Этап 1. Минимальный прототип с конфигурацией**.

Структура репозитория:

```
src/            исходный код
tests/          модульные тесты
tests/data/     тестовые репозитории
tests/scripts/  демонстрационные скрипты
run.sh          скрипт запуска
```

## Описание функций и настроек

Источником настраиваемых параметров являются опции командной строки.

| Опция | Описание |
| --- | --- |
| `--package ИМЯ` | имя анализируемого пакета |
| `--repo-url ИСТОЧНИК` | URL репозитория или путь к файлу тестового репозитория |
| `--test-mode` | режим работы с тестовым репозиторием |
| `--version ВЕРСИЯ` | версия пакета |
| `--output ФАЙЛ` | имя генерируемого файла с изображением графа |

Значения по умолчанию: `--repo-url https://index.crates.io`,
`--output graph.svg`.

При запуске приложение печатает все настраиваемые параметры в формате
«ключ-значение».

### Обработка ошибок

Ошибки параметров выводятся в поток ошибок строкой `ошибка: <описание>`,
код возврата 1:

* `не задано имя пакета (--package)`;
* `недопустимое имя пакета: ...` — имя содержит недопустимые символы;
* `имя пакета тестового репозитория должно состоять из заглавных
  латинских букв: ...`;
* `не задан источник данных (--repo-url)`;
* `URL репозитория: ...` — URL без схемы `http://` или `https://`;
* `файл тестового репозитория не найден: ...`;
* `не задана версия пакета (--version)` — вне тестового режима;
* `недопустимая версия пакета: ...` — версия не вида `1.2.3`;
* `не задано имя файла изображения (--output)`;
* `файл изображения должен иметь расширение .svg: ...`;
* `каталог для изображения не найден: ...`.

В тестовом режиме имя пакета состоит из заглавных латинских букв, а
версия пакета не требуется.

## Сборка и запуск

Сборка не требуется, нужен только Python 3.

```bash
./run.sh --package serde --version 1.0.219
```

Запуск тестов:

```bash
python3 -m unittest discover -s tests -t .
```

Демонстрация вывода параметров и всех ошибок:

```bash
sh tests/scripts/stage1_demo.sh
```

## Примеры использования

```
$ ./run.sh --package serde --version 1.0.219 --output graph.svg
package   = serde
repo-url  = https://index.crates.io
test-mode = нет
version   = 1.0.219
output    = graph.svg
```

```
$ ./run.sh --package A --test-mode --repo-url tests/data/simple.graph
package   = A
repo-url  = tests/data/simple.graph
test-mode = да
version   = <не задано>
output    = graph.svg
```

```
$ ./run.sh --package serde --version 1.x
ошибка: недопустимая версия пакета: 1.x
```
